# 中文排版规范（产品文档版）

目的是让文档整洁、好读、全篇一致。规则有冲突时以用户或团队的规范为准，并告诉用户哪几条和本规范不同。

代码块、行内代码、命令、文件路径、URL、链接目标、界面上显示的原文、数据表中的值，一律不改。

## 统一取舍（常见分歧已定）

| 项目 | 本规范 | 说明 |
|---|---|---|
| 引号 | 中文弯引号“”，嵌套用‘’ | 团队用直角引号「」时整篇换成「」，不要混用 |
| 中文与数字 | 加半角空格：`共 3 个文件` | |
| 数字与单位 | 加空格：`10 GB`、`200 ms`；百分号和度数不加：`95%`、`32°C` | |
| 括号 | 中文句子里一律全角（），即使括号内有英文或数字：`任务栏（macOS 为菜单栏）` | 整句英文时用半角 |
| 省略号 | 中文用 `⋯⋯`；不和“等”连用 | |
| 只有一个子标题 | 一般删掉这个子标题，内容并入上级 | 用户明确要求单独成节时保留 |

## 空格

- 中文与英文之间加一个半角空格：`登录 SyncBox 账号`。
- 中文与数字之间加空格；数字与单位之间加空格（见上表）。
- 全角标点前后不加空格：`详见 LICENSE 文件。`
- 链接文字两侧：与中文相邻时加空格，与全角标点相邻时不加：`请参考 [设置说明](…)。`

## 标点

- 中文句子用全角标点，整句英文用半角标点。
- 句号、逗号、顿号、分号、冒号、问号、叹号不能出现在行首。
- 标题末尾不加句号、逗号、冒号；问号可以（FAQ 标题）。
- 并列词用顿号：`文件、文件夹和链接`。最后一项前用“和”或“或”。
- 不要一逗到底：一段话只有逗号和最后一个句号时，在意思完整的地方断成句号或分号。
- 冒号：解释说明用全角“：”；时间用半角 `10:30`。
- 感叹号：使用文档里基本不用，绝不连用。
- 菜单路径用半角 `>` 两侧加空格，整体加引号：打开“设置 > 网络 > 限速”。
- 界面上的按钮名、选项名用弯引号括起来，不用粗体：点击“恢复”。
- 括号补充说明时，句号放在括号外。

## 数字

- 一律使用半角阿拉伯数字。技术参数不用中文数字（写“100 个”，不写“一百个”）。
- 五位及以上的数加千分位逗号：`10,000`；四位可选，全篇统一。
- 范围用 `～` 或“至”，两端都带单位：`1 GB～2 GB`。
- 金额：`¥99`、`99 元`，全篇统一一种。
- “增加了”表示增量，“增加到”表示结果；不要写“降低 N 倍”。

## 句子

- 一个句子或一个逗号分隔的成分尽量不超过 20 个字；超过 40 字必须拆。
- 优先用简单句和并列句，一句只说一件事。
- 优先用主动句：“SyncBox 会保留两份文件”比“两份文件会被保留”清楚。
- 优先用肯定句：“请先关闭文件”比“请确认文件未处于打开状态”好懂。
- 代词“其”“该”“此”必须指代明确，不明确就重复名词。
- 名词前不要堆多个定语，定语太长就拆句。
- 正确使用“的、地、得”。

## 段落与标题

- 一段只讲一件事，主题句放段首。屏幕上超过 4 行就考虑拆分或改成列表。
- 标题层级不跳级：二级标题下面直接是三级，不能直接出现四级。
- 下级标题不重复上级标题里的词。
- 四级标题慎用；并列的短内容用列表代替。

## 术语

- 产品名、品牌名、通用缩写保留英文：API、Wi-Fi、PDF、macOS、Windows。
- 有公认中文译法的用中文：浏览器、文件夹、设置。
- 首次出现的生僻术语括号注中文或英文：`提取码（访问密码）`，后文直接用。
- 同一个东西全篇只用一个叫法。不要一会儿“共享链接”一会儿“分享链接”。以产品界面上的叫法为准。
- 大小写跟官方写法：`macOS`、`iPhone`、`GitHub`。

## 文件名（交付多个文件时）

全小写英文、用连字符分隔、不含空格和中文：`share-files.md`。
