# 读者测试

## 怎么选问题

5～8 个，写成读者会在搜索框或客服对话里打的原话。至少覆盖：

- 最核心的那件事怎么做（应该能答对）
- 版本差异：免费版能不能……
- 平台差异：我用的是 Mac/手机……
- 出错：失败了/图标变黄了怎么办
- 边界：过期、超限、空间满了以后……
- 撤销：做错了能恢复吗

## 提示词模板

把 `<文档全文>` 和 `<问题列表>` 替换后，交给子代理；没有子代理时，请用户在一个新对话里粘贴。

```text
你是一名普通用户，第一次看这份产品帮助文档。只能依据文档内容回答，不能用常识或猜测补充产品功能。文档没写的，直接回答“文档没写”。

<document>
<文档全文>
</document>

请逐题回答。每题给出：
(a) 答案；
(b) 文档里含糊或不清楚的地方；
(c) 文档默认你已经知道的东西。

<问题列表>

最后回答：
A. 这份文档有哪些地方可能让读者误解？
B. 有没有前后矛盾或叫法不一致的地方？
C. 有没有失效或指向不明的链接？

用简洁的中文回答。
```

## 怎么处理结果

| 结果 | 处理 |
|---|---|
| 答对 | 不动 |
| 答错（误解） | 改写那一处，通常是句子有歧义或步骤顺序不清 |
| “文档没写”，材料里有答案 | 补进文档最相关的位置 |
| “文档没写”，材料里也没有 | 正文标 `【待确认：……】`，加入待确认清单 |
| 指出的“默认前提”读者未必知道 | 补一句或链接到快速上手或参考页 |

修改后最多再测一轮，只测上一轮出问题的题，而且要换一个新的子代理，避免它记得上一版。
